# Kevyworks Portfolio — React + Tailwind

A responsive portfolio website built from the supplied CV and shaped around the Kevyworks product/portfolio identity.

## Includes

- Responsive desktop/tablet/mobile navigation
- Hero section with developer positioning
- Selected work / project cards
- Dedicated **Product Space** for Kevyworks products
- Experience timeline
- Skills and recognition
- Contact CTA + social links
- Dark, editorial/product-studio visual language
- Tailwind CSS utility styling
- TypeScript data-driven content

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Customize

Edit `src/data/content.ts` to update projects, products, skills and experience.

The product cards currently use the Kevyworks product URLs supplied/identified for the portfolio concept. Replace or add real product URLs/screenshots as needed.

## Deployment

The generated project is Vite-based and can be deployed to Vercel, Netlify, Cloudflare Pages, or any static hosting service that supports a Vite build.
